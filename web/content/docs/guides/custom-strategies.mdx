description: Implement, register, and configure custom rotation strategies using the RotationStrategy protocol.

ProxyWhirl strategies are **protocol-based** — any class with `select()` and `record_result()` methods works. No inheritance required.

> **See also:** [Rotation Strategies](/docs/concepts/rotation-strategies) for built-in algorithms, [Strategy Matrix](/docs/generated/strategies) for the generated inventory, and [Configuration](/docs/guides/configuration) for TOML wiring.

## Minimal Implementation

```python
from __future__ import annotations

from urllib.parse import urlparse

from proxywhirl import Proxy, ProxyPool, ProxyWhirl, SelectionContext
from proxywhirl.exceptions import ProxyPoolEmptyError
from proxywhirl.strategies import StrategyRegistry


class PreferLowPortStrategy:
    """Pick the healthy proxy with the lowest port number."""

    def select(self, pool: ProxyPool, context: SelectionContext | None = None) -> Proxy:
        proxies = pool.get_healthy_proxies()
        if not proxies:
            raise ProxyPoolEmptyError("No healthy proxies available")
        return min(proxies, key=lambda p: urlparse(str(p.url)).port or 0)

    def record_result(self, proxy: Proxy, success: bool, response_time_ms: float) -> None:
        pass  # Stateless — no feedback needed
```

`ProxyPool` exposes `get_healthy_proxies()` / `get_all_proxies()` — there is no `get_available()`. `Proxy` stores `url` (not a `.port` attribute); parse the URL when you need host/port.

## Use at Runtime

Pass an instance to the constructor or hot-swap with `set_strategy`:

```python
rotator = ProxyWhirl(bootstrap=False, strategy=PreferLowPortStrategy())
# ...
rotator.set_strategy(PreferLowPortStrategy())
rotator.set_strategy("performance-based")  # built-in name also works
```

`ProxyWhirl` does **not** expose a `strategy_registry` attribute. Use a standalone `StrategyRegistry` when you want named lookup:

```python
registry = StrategyRegistry()
registry.register_strategy("prefer-low-port", PreferLowPortStrategy)
strategy_cls = registry.get_strategy("prefer-low-port")
rotator.set_strategy(strategy_cls())
```

`set_strategy(strategy, *, atomic=True)` accepts a `RotationStrategy` instance or a built-in name string (`round-robin`, `random`, `weighted`, `least-used`, `performance-based`, `session`, `geo-targeted`, `cost-aware`). Custom names are only resolved if you construct the instance yourself (or via your own registry).

## Configure via TOML

```toml
[strategy]
name = "performance-based"
```

Built-in names are resolved by the rotator. Custom classes must be constructed in code and passed as instances — TOML cannot import arbitrary Python classes.

## Stateful Strategies

Adaptive strategies should update internal state in `record_result()`:

```python
class SuccessRateStrategy:
    def __init__(self) -> None:
        self._scores: dict[str, float] = {}

    def select(self, pool: ProxyPool, context: SelectionContext | None = None) -> Proxy:
        proxies = pool.get_healthy_proxies()
        if not proxies:
            raise ProxyPoolEmptyError("No healthy proxies available")
        return max(proxies, key=lambda p: self._scores.get(str(p.id), 0.5))

    def record_result(self, proxy: Proxy, success: bool, response_time_ms: float) -> None:
        key = str(proxy.id)
        prev = self._scores.get(key, 0.5)
        self._scores[key] = prev * 0.9 + (1.0 if success else 0.0) * 0.1
```

Use locks when sharing state across threads — see [Rotation Strategies](/docs/concepts/rotation-strategies#thread-safety).

## Composite Pipelines

`CompositeStrategy` takes **filters** plus an optional **selector** (not a single list of strategies):

```python
from proxywhirl.strategies import (
    CompositeStrategy,
    GeoTargetedStrategy,
    PerformanceBasedStrategy,
)

pipeline = CompositeStrategy(
    filters=[GeoTargetedStrategy()],
    selector=PerformanceBasedStrategy(),
)
rotator = ProxyWhirl(bootstrap=False, strategy=pipeline)

# Geo filters read SelectionContext.target_country / target_region
proxy = rotator.strategy.select(
    rotator.pool,
    SelectionContext(target_country="US"),
)
```

## Testing

```python
def test_prefer_low_port_selects_smallest_port(sample_pool):
    strategy = PreferLowPortStrategy()
    proxy = strategy.select(sample_pool, context=None)
    ports = [urlparse(str(p.url)).port or 0 for p in sample_pool.get_healthy_proxies()]
    assert (urlparse(str(proxy.url)).port or 0) == min(ports)
```
